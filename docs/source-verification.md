# Проверка фактов презентации

Сверка с публичным основным репозиторием выполнена 29 октября 2026 года по актуальному main, README, открытым Issues и доступной истории Pull Requests. Презентация не меняет основной репозиторий.

## Подтверждённые возможности

- Последний опубликованный в README релиз на дату сверки — Study Agent v1 Beta 6.1 для macOS 14+ и Apple Silicon. В релизном описании указано распознавание страниц PDF, встроенных изображений DOCX и локальных изображений Markdown при установленном Chandra OCR.
- Документированные форматы: PDF, DOCX, Markdown, текстовые файлы и изображения. Цифровой текст извлекается напрямую; Chandra — дополнительный компонент для визуального содержимого.
- SQLite хранит индекс документов и фрагменты; FTS5 обеспечивает лексический поиск. Семантический и гибридный режимы доступны отдельно и требуют выбранной embedding-модели и подготовленного индекса.
- Ответ можно запросить через локальную LLM Ollama по найденным фрагментам. Поиск доступен и без генерации. Источники строятся из метаданных поиска и позволяют проверить, какие фрагменты использовались; они не гарантируют истинность ответа.
- Для Windows 28 октября 2026 опубликован Beta 6.1 как prerelease с установщиком для Windows 10/11 x64 и Windows 11 ARM64 через эмуляцию x64. Issue SA-05 и PR #13 остаются открытыми, поэтому в слайдах она названа предварительной версией, а не завершённой стабильной поставкой. Описание выпуска сообщает, что GitHub Actions проверили установку, запуск процесса, распаковку backend, синтетический поиск и удаление с сохранением данных. Интерактивная приёмка, установка на Windows 10, OCR с весами, Ollama, accessibility и масштабирование всё ещё не прошли полную проверку.
