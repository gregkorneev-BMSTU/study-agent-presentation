# Study Agent — презентация

Установите Node.js 20+ и выполните `npm install`, затем `npm run dev`. Для переносимой сборки: `npm run build`, затем `npm run present`. Откройте адрес локального сервера в браузере. Стрелки и пробел управляют слайдами и шагами, F включает полноэкранный режим, S открывает окно докладчика. Интернет при показе не требуется.

ФИО, группы и роли добавляются в `src/data/team.js`. Состав команды требует подтверждения. Короткие заметки находятся в `src/main.js` в секциях `aside.notes`. `npm run export:pdf` использует Playwright и Chromium (`CHROMIUM_PATH` задаёт путь к браузеру). Для ручного экспорта откройте адрес с `?print-pdf` в Chromium и сохраните через печать с фоновыми изображениями.

Снимки приложения и иконка взяты из исходного репозитория Study Agent. Liquid Glass for Web распространяется под лицензией MIT; лицензия находится в node_modules/liquid-glass-web/LICENSE.
