# Study Agent — университетская презентация

Интерактивная презентация из девяти слайдов на Reveal.js. Она собирается локально, показывает настоящие экраны Study Agent и работает без сетевых ресурсов после установки зависимостей.

## Требования

- Node.js 20 или новее.
- Для PDF — Chromium, установленный Playwright; при необходимости можно указать системный браузер через CHROMIUM_PATH.

```bash
npm install
npx playwright install chromium webkit
npm run dev
```

Откройте адрес, который покажет Vite (обычно http://127.0.0.1:5173). Для production-сборки выполните npm run build, затем запустите npm run present.

## Как показывать презентацию на Mac

1. В терминале проекта выполните npm run present (или npm run dev для разработки) и откройте локальный адрес в Chrome или Safari.
2. Подключите проектор или внешний монитор в настройках macOS. Выберите расширенный рабочий стол и перетащите окно браузера на экран проектора.
3. Нажмите F для полноэкранного режима; Esc возвращает окно. Стрелки влево/вправо и пробел перемещают слайды и их шаги. Для перехода сразу между слайдами используйте Page Up / Page Down.
4. Нажмите S, чтобы открыть Speaker View. В Reveal.js это отдельное окно с текущим и следующим слайдом, заметками и таймером; при двух мониторах переместите его на экран докладчика, а презентацию оставьте на проекторе. Разрешите всплывающие окна для локального адреса, если браузер спросит.
5. Заметки сейчас короткие и технические. Чтобы добавить текст выступления позже, отредактируйте соответствующие элементы <aside class="notes">…</aside> в src/main.js; не вставляйте заметки в видимую часть слайда.
6. Для изменения состава откройте src/data/team.js. Неуточнённые ФИО, группы и роли оставлены пустыми намеренно.
7. Для экспорта в PDF установите Chromium Playwright командой npx playwright install chromium, затем запустите npm run export:pdf. Можно указать установленный Chrome/Chromium: CHROMIUM_PATH="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" npm run export:pdf.

Презентация использует локальные файлы из public/assets/. Liquid Glass for Web выбирает SVG-преломление в Chromium и автоматически использует полупрозрачный CSS fallback в Safari; это упрощение эффекта, а не ошибка загрузки.

## Проверки и материалы

```bash
npm run build
npm run present
npm run export:pdf
npm run verify
```

npm run export:pdf ждёт доступности локального сервера, дожидается декодирования ресурсов, экспортирует завершённые состояния слайдов и проверяет, что PDF содержит ровно девять страниц. npm run verify пересобирает сайт, обновляет PNG-кадры, проверяет фрагменты, навигацию вперёд/назад, быстрые переходы, изображения, локальные сетевые запросы, переполнение на трёх 16:9-разрешениях, reduced motion и клавишу Speaker View. Сервер запускается как дочерний процесс Vite и закрывается при успехе или ошибке.

Актуальные PNG-снимки слайдов находятся в screenshots/; промежуточные состояния архитектуры сохраняются рядом. dist/ — production-сборка. PDF и ZIP в корне проекта — итоговые материалы. Документация: docs/animations.md, docs/source-verification.md.

## Состав проекта

- src/main.js — девять слайдов, Reveal.js, стеклянные поверхности и привязка GSAP к событиям слайдов.
- src/animations/architecture.js — timeline архитектуры с явным восстановлением по шагу.
- src/data/team.js — редактируемые данные команды.
- public/assets/ — иконка, настоящий QR-код и скриншоты приложения Beta 6.1.
- scripts/export-pdf.js — переносимый PDF-экспорт через Playwright.

Устный доклад намеренно не включён.
